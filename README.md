# 울트라킬 한글모드

이 모드는 **UltrakULL ReFORKED** 모드를 기반으로 한국어 전용으로 수정한 버전입니다.

# 기능

- 모든 텍스트 번역
- 모든 텍스처 번역
- ~~모든 오디오 더빙~~ (계획은 있으나 확실하지는 않습니다)
(관련해서 도움을 주실 수 있다면 연락해 주시면 감사하겠습니다)

# 다운로드 및 설치

모드를 사용하기 위해선 Thunderstore, r2modman, Gale 같은 모드 매니저가 필요합니다.\
\
모드 매니저를 설치 후 검색창에 UltraKorean을 입력하고 다운로드 후 실행하시면 됩니다.\
주의: 원본 UltrakULL이 있을경우 원본 모드를 끄거나 제거해 주세요.
